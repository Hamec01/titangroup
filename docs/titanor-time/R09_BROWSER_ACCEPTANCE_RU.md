# R09 — browser-acceptance чек-лист

- **Основание:** production release roadmap R09.11, ТЗ §13–15 + §18.2 (browser-lane гоняется на
  пилот-приёмке / R12). Здесь — ручной чек-лист по тому, что **изменил именно R09**; не полная
  регрессия приложения.
- **Дата:** 2026-08-30.
- **Не-browser регрессия R09** уже зелёная в CI (unit + db + scheduler). Этот документ — для прогона
  в реальном браузере на пилоте.
